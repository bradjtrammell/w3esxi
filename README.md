## About W3ESXi

W3ESXi was a WHMCS module designed to provision and manage virtual servers on VMware ESXi hosts, including setups with multiple hosts.

The project originated from code written for earlier PHP versions and was later adapted for PHP 7-era WHMCS installations. Its source and documentation remain available to preserve the project's history; they are **not** a supported distribution.

## Historical compatibility

> [!IMPORTANT]
> **Legacy version information is not a compatibility guarantee.**
>
> The last documented release was **0.8.0**, dated **February 6, 2022**. Original documentation referenced **PHP 7.0+** and **WHMCS 7+**. Those statements describe the project's historical target environment, **not** verified compatibility with current PHP, WHMCS, VMware ESXi, or vSphere releases.

The archived installation notes are available in [INSTALL](INSTALL) strictly as a historical reference. They should not be used as current deployment guidance.
