# W3ESXi — Retired

> **PROJECT RETIRED — NO LONGER MAINTAINED OR SUPPORTED**
>
> W3ESXi has been discontinued. There will be **no further development, updates, security fixes, compatibility updates, or support**. **Do not use this repository for new or production deployments.**

## About the project

W3ESXi was a WHMCS module for managing virtual servers on VMware ESXi hosts. It originated as a module for older PHP versions and was subsequently adapted toward PHP 7 and WHMCS 7-era environments.

The implementation and documentation in this repository are historical. They should **not** be taken as evidence of compatibility with current versions of PHP, WHMCS, VMware ESXi, or vSphere.
